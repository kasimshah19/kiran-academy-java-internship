# Recruitment & Placement Management System

A static HTML and CSS UI prototype of 12 pages for Kiran Academy, Pune, designed to streamline candidate tracking, corporate drives, interview coordination, and placement analytics.

## Prototype Pages

1. **login.html** - Sign-in authentication portal with role selection and split branding banner.
2. **dashboard.html** - Executive dashboard featuring key metrics, funnel overview, upcoming interviews, and recent placements.
3. **candidates.html** - Searchable candidate directory with multi-criteria filters, profile listings, and pagination.
4. **candidate-form.html** - Candidate registration and edit interface with academic history, skills selection, and inline validation states.
5. **candidate-details.html** - Comprehensive candidate overview featuring academic records, skill badges, and application history.
6. **companies.html** - Corporate hiring partners directory and integrated organization registration form.
7. **jobs.html** - Active recruitment drives directory with status breakdown, openings count, and compensation details.
8. **job-form.html** - Job posting creation and update form with eligibility criteria, package parameters, and validation rules.
9. **applications.html** - End-to-end application lifecycle tracking with pipeline stages, eligibility indicators, and alert banners.
10. **interviews.html** - Interview scheduling module with round configuration, panelist assignment, and outcome tracking.
11. **placement-process.html** - Multi-stage placement workflow featuring a progress stepper, tabbed panels for feedback, offer letters, and joinings.
12. **reports.html** - Placement performance analytics, partner distribution, technology metrics, and recruiter conversion rates.

## How to Open and Explore

To view the prototype:
1. Open login.html in any modern web browser (such as Google Chrome or Microsoft Edge).
2. Click the primary "Login" button to access the main system dashboard.
3. Use the left navigation sidebar to browse across all 12 modules and workflows.
